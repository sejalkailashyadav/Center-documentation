## 🔹 STATUS FLOW (Very Important)

        ### 🟡 1. Review (Default)
        * When manager creates student
        * Status = **Review**
        * Admin approval pending
        * Both Admin & Sueramdin  can Accept entry

        ### 🟢 2. Active
        * Admin or Manager accepts entry
        * Student is under active program


        ### 🟠 3. Withdrawal
        * Manager enters:
          * Withdrawal date
          * Notes
        * Status becomes Withdrawal
        * Awaiting withdrawal confirmation

        ### 🔴 4. Archive
        * When withdrawal date is passed
        * Automatically next day status = Archive
        * No longer active in system
